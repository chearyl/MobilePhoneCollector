# Mobile Phone Collector

A WinUI 3 desktop app for looking up and collecting mobile phone specifications by entering a phone model.

## Features

- Scrap mobile phone data from GSMArena or user self input.
- Insert any specs data with category.
- View the available specs for a phone.
- Edit anytime.
- Support attach phone image and review doc.
- fully offline except for scrapping part.
